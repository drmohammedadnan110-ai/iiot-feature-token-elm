# Executed validation

Local validation completed on 2026-10-06:

- 30 pytest cases passed, including all nine random-map/activation combinations against an independent augmented least-squares solution, TRAIN-only preprocessing, transitive group leakage rejection, model round-trip, unavailable TEST data during training, locked TEST integrity, leave-one-attack-out exclusions, and identity transfer.
- Ruff checks passed. Python modules/scripts/tests and all notebook code cells compiled.
- Five complete synthetic proposed-model fits and five logistic baseline fits ran using seeds 7, 13, 21, 42, 99 on a shared split. The run used 1,080 toy rows: 691 TRAIN, 173 VALIDATION, 216 TEST. Observations are Gaussian synthetic features, not network captures.
- Proposed-model synthetic mean TEST Macro-F1 was 0.839323; the logistic baseline was 0.807885. The logistic solver is deterministic for this setup, so its repeated scores are identical. These comparisons exercise statistical code and do not establish real-data superiority.
- The project page was inspected in a browser, and generated figures were visually checked.

Each seed's actual software versions, model dimensions, selected epoch, temperature and source hashes are in `results/executed/synthetic_demo/seed_*/training_provenance.json`. Models were fitted on CPU, with two PyTorch threads, Python 3.10 and the recorded package versions. Local paths are redacted in the public reports. Training and test provenance hashes refer to the original local bundles; the published training-provenance JSON is a redacted report, not that original bundle file. Numeric model bundles remain local and are regenerated by the demo command.

The synthetic reports include a checksum manifest. Verify it with `python scripts/verify_artifacts.py`. New code commits may change generated results; use the original release commit and matching environment for comparisons. Exact floating-point identity across hardware and package versions is not promised.

Not executed: original corpus training, author-checkpoint reproduction, full 100-trial optimization, optional boosting packages, real cross-dataset transfer, GPU/industrial-hardware deployment, or real unknown-attack detection. The hyperparameter-search regression test verifies orchestration with a stubbed training function; it is not a completed real-data search.
